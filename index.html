    HOW IT WORKS

    规则 / RULES

    只数站错位置的数字。

    系统选定一个三位数，它不会显示给你。你通过提问收集反馈，最后在独立的提交区确认答案。

    01 系统藏起的数

    是一个三位数：首位为 1–9，三个数字互不重复。0 可以出现在第二、三位，例如 102、470。

    02 反馈怎么算

    • 数字正确，但位置不对每个记 1
    • 数字正确，位置也对记 0
    • 数字根本不在答案里记 0

    因此反馈只可能是 0、1、2、3。它只统计“错位”的数字，不告诉你哪些数字错位。

    124→01、2 位置正确；4 不存在
    214→21、2 正确但都错位；4 不存在
    231→3三个数字都在，且都站错位置
    123→0答案就是 123，提问区仍然只返回 0

    以上例子均假设系统答案为 123。

    03 提问与最终提交

    开局前选择 7–12 次提问。合法提问会消耗 1 次；输入不合法不会消耗。提问用尽后不能再问，但仍可使用剩余的提交机会。

    每局有 3 次最终提交机会。提交错误会消耗 1 次，并且不会给出任何数字级提示；第 3 次错误后本局结束并揭晓答案。提交正确则立即胜利。

    0

    别忘了 0 的歧义。反馈 0 可能是“正好猜中”，也可能是“没有任何错位数字”。查询区永远不会判定胜利。
